Developed a Vue.js-based e-commerce platform for browsing and purchasing colognes, featuring secure user registration and login. Utilized ASP.NET Core (C#) with Entity Framework Core to construct a robust back-end that manages a dynamic product catalog, interactive shopping cart, and real-time checkout process. Integrated JWT Authentication to ensure secure access and maintain data integrity. The project demonstrates strong skills in front-end development, back-end engineering, database management, and application security.


The Microsoft Server SQL database is hosted locally on my computer, so please watch the video on this GitHub to view the functionality if you're viewing the code.
